# CJM: торговля CS2 на Polymarket

Пользователь — один трейдер, ставит на киберспорт (сейчас только CS2) через API Polymarket.

| # | Этап | Что делает пользователь | Что даёт система | Статус |
|---|------|-------------------------|------------------|--------|
| 1 | Подключение | Заполняет `.env` (адрес кошелька, приватный ключ, Relayer API key) | `scripts/check_env.py` проверяет ключи и подписанта | готово |
| 2 | Сбор истории | Запускает сбор за период | SQLite с матчами CS2, рынками, поминутными ценами; раунды/стороны по картам | в работе |
| 3 | Проверка гипотез | Формулирует гипотезу (напр. «камбэк фаворита после проигранной 1-й половины») | Отчёт: калибровка цен, частота исходов, ожидаемая прибыль с учётом комиссии и спреда | план |
| 4 | Бумажная торговля | Включает стратегию без денег | Сигналы и виртуальные сделки по живым матчам, журнал результатов | план |
| 5 | Ставки с подтверждением | Подтверждает сигнал вручную | Бот выставляет ордер по подтверждению, лимиты на сумму | план |
| 6 | Автоторговля | Задаёт банк и лимиты | Бот сам входит/выходит по стратегии, риск-лимиты, логирование | план |

## Гипотезы (этап 3)

1. **Камбэк фаворита.** Явный фаворит (цена победы до матча ≥ ~0.70) проиграл первую половину карты; аутсайдер набрал её на CT. Рынок переоценивает счёт → покупка фаворита на карту.
2. **Стоп-лосс фаворита.** Ставка на фаворита до матча, продажа при отставании. Противоречит гипотезе 1 — проверяются одним анализом калибровки.
3. Новые гипотезы — из анализа данных (калибровка цен по ходу карты, по турнирам, по картам).
