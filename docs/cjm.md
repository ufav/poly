# CJM: торговля CS2 на Polymarket

Пользователь — один трейдер, ставит на киберспорт (CS2; Dota 2 — исследование) через API Polymarket. Теннис (ATP/WTA/ITF) — этап 2–3: история собрана (D-19), источники связаны (D-20, `tennis_links`); дальше калибровка и гипотезы (A-46). По объёму рынков матча теннис в разы больше киберспорта.

| # | Этап | Что делает пользователь | Что даёт система | Статус |
|---|------|-------------------------|------------------|--------|
| 1 | Подключение | Заполняет `.env` (адрес кошелька, приватный ключ, Relayer API key) | `scripts/check_env.py` проверяет ключи и подписанта | готово |
| 2 | Сбор истории | Запускает сбор за период | SQLite с матчами CS2, рынками, поминутными ценами; раунды/стороны по картам; составы и места турниров | готово (год: сен 2025 — окт 2026) |
| 3 | Проверка гипотез | Формулирует гипотезу (напр. «камбэк фаворита после проигранной 1-й половины») | Отчёт: калибровка цен, частота исходов, ожидаемая прибыль с учётом комиссии и спреда (`analysis/`, итоги в `docs/research.md`) | в работе |
| 4 | Бумажная торговля | Поднимает бота на сервере (`docker compose up -d`), получает сигналы и итоги дня в Telegram, смотрит отчёт `paper_report.py` | Регистратор всех live-матчей CS2 (счёт со временем, стакан), бумажные сделки по правилам с исполнением по реальному стакану, расчёт P&L | в работе |
| 5 | Ставки с подтверждением | Подтверждает сигнал вручную | Бот выставляет ордер по подтверждению, лимиты на сумму | план |
| 6 | Автоторговля | Задаёт банк и лимиты | Бот сам входит/выходит по стратегии, риск-лимиты, логирование | план |

## Гипотезы (этап 3)

1. **Камбэк фаворита.** Явный фаворит (кэф до матча ≲ 1.43) проиграл первую половину карты → покупка фаворита. **Не подтвердилось (R-8 −17%; paper −13…−32%)** — из бота убрано (T-21).
2. **Стоп-лосс фаворита.** Ставка на фаворита до матча, продажа при отставании. **Преимущества нет (R-2).**
3. **Лидер в перерыве недооценён** (лидер +6 / +4): история +3.5% (R-8); paper live_copy (R-26) — плюс в кармане прематч кэф **1.54–2.00** и вход не короче **~1.25**. В боте фильтры включены (T-22); дефолт: `leader_half`, `leader_half6`, `fav_band_t1`. `leader_late` / камбэки / maker — выкл. по умолчанию. Tier1 лайв: фаворит кэф ~1.09–1.43 недооценён 2–3 п.п. (R-14/R-15) — `fav_band_t1`; `maker_t1` opt-in.
4. Не подтвердились: стадия/уровень турнира (R-4), джетлаг и домашние стены (R-5), кураж — серия раундов (R-9) и форма лидера команды (R-10).

## Dota 2 (этапы 2–3)

Рынок больше CS2 по объёму: ~3 000 событий за год, рынки карт $666M, матчей $462M (D-14). Рынки событий в игре (рампага, Рошан, бараки, «днём», тоталы убийств) — без ликвидности, не торгуем (A-38). План: те же проверки, что дали результат в CS2 — калибровка реальных сделок и мейкер в лайве tier1 (A-36), затем состояние игры из OpenDota (золото по минутам) против цены карты (A-37).

Этап 4 для Доты (T-17): контейнер `paper-bot-dota` — на tier1 BO3 после проигранной карты 1 бумажная покупка проигравшего на карту 2 (R-20; аутсайдер кэф 2.0–2.5, 2.5–3.33 и любой проигравший — три отдельных банка, 1%). Сигналы и итоги дня в тот же Telegram; судить после 2–3 крупных турниров (~100 сигналов).

Теннис (A-46 / T-20 / R-27): после сета 1 на истории VWAP плюс; paper — тонкий плюс у фаворита после своего S1 (+1.5%). В боте по умолчанию только `tennis_fav_s1`, вход кэф **1.10–1.30** (T-24); dog / любой победитель S1 — выкл.

Волейбол (D-21 / A-48): Polymarket тонкий (~$183k, 213 матчей); Olimpbet 104 — сеты собраны. Прематч на PM без края (R-25). Дальше — связка и анализ по сетам, если объём PM вырастет или найдётся исполнимый рынок.

Данные для гипотез (D-16): каждая карта Polymarket связывается с игрой OpenDota (драфт, герои и игроки, золото/опыт по минутам, Рошан/башни со временем, тимфайты) и с матчем cybersport (кто играл, город, призовые, стадия, коэффициенты букмекера); PandaScore добавляет LAN/онлайн, страну и tier турнира, страну команды, переносы матчей. Гипотезы — A-39.

Этап 4 (бумажная торговля) сейчас нужен прежде всего как **регистратор**: живой счёт раундов с настоящим временем + стакан + цены — единственный способ честно проверить гипотезы о состоянии карты (перерыв, сторона, отставание).
